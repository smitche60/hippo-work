# Sources

What the assistant may read outside this folder. Rules: AGENTS.md, "Reaching outside the
brain". A source is **listed** when it has a line under `## Read` below. Nothing is listed
by default, and only the owner adds a line. A source that is not listed is not read. Email
and social feeds can never be listed.

A line has the shape `- kind — which one — any limit`, and the kind is one of five words.
`calendar`: today's meetings in the morning brief, and the "met" line in the dream. `chat`:
a team chat workspace, read only through channels that pages name; the voice build, when
the owner asks for it, also reads the owner's own messages there. `documents`: a document
drive. `crm`: a customer-relationship system. `web`: searching and opening public pages.

Everything listed is used to fetch and for nothing else. The owner removes a line to stop.

## Skills the work run may use

One line per skill, by its exact name, added by the owner. List only skills that fetch: a
work run never runs a skill that is not listed here, and never one that sends or creates
anything outside this folder.
