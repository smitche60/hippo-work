# Watched sources

Empty by default, and it stays that way unless you add a line (AGENTS.md, "Writing").

If you do list a folder here, every dream sweeps it: new or changed text files (.md, .csv,
.txt) are distilled through the redactor — never copied. Binaries, zips, and screenshots are
skipped. Paths are relative to the folder this repo lives in. State: `.dream-state.json`
(gitignored). Remove the line to stop.
